## ⭐ Ma reco de départ (stack minimal, coût maîtrisé)
1. **HeyGen** — un présentateur FR qui explique (le cœur d'une marque éducative).
2. **Higgsfield** (avec Seedance) — pour tester rapidement des vidéos d'accroche.
3. **Canva** ou **Ideogram** — visuels de posts.
4. **ElevenLabs** — voix off FR si besoin.
→ Open Design reste le **chef d'orchestre du branding** (cadre, couleurs, logo) ; ces outils **remplissent** les médias.

## 🔎 Comment choisir
- **Priorité FR-Québec** → HeyGen + ElevenLabs (voix française).
- **Marque financière = prudence droits** → privilégie **Firefly** (licencié) pour les images publiées.
- **Budget serré** → commence par les **plans gratuits** (HeyGen, Canva, Ideogram, ElevenLabs) avant de payer.
- **Veux du cinématique sans te ruiner** → **Higgsfield** (un abo, plusieurs modèles).

## ⚠️ Garde-fous (valables pour TOUT outil)
- Jamais « **planificateur / conseiller financier** », **aucune promesse de rendement** → rester « **outil éducatif** ».
- **Pas de deepfake** de vraies personnes ni de **faux témoignages** (risque AMF + confiance).
- Toujours : **wordmark vert** « PlanFin » + **icône bleu nuit** (favicon).
